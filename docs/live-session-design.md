# Live Session 體驗與品牌一致性調整

## 設計依據

沿用現有 `BrandLogo`、暖白背景、深色主按鈕、共享語意色票、圓角面板與 PageHeader。範圍為加入頁、學生互動頁、講師工作區、場次列表及建立流程；不更換框架，不改資料庫、API、權限或 realtime 事件契約。

## 使用流程

- **場次管理**：標題／代碼搜尋、全部／尚未結束／已結束篩選、可重試的錯誤狀態，以及可開始操作的空狀態。工作區連結直接導覽，避免不必要的新分頁。
- **建立場次**：分開課堂資訊與第一道投票，提供下一步說明與 2–6 選項提示。未填妥名稱、題目及至少兩個選項時不能送出。建立後由使用者主動開啟工作區，避免非同步 `window.open` 被阻擋，並提供複製失敗提示。
- **講師工作區**：加入代碼與邀請操作集中，暫停／繼續／重新開啟依狀態顯示，結束前需確認。狀態更新期間防止重複操作，失敗時回復原狀態。合併題目、完整選項、票數與百分比，課堂節奏與問答呈現於桌面側欄。新增投票使用可保留草稿的 Dialog；教材、測驗載入與全螢幕投影入口保留。
- **學生互動**：作答優先、選擇狀態與送出提示明確、暫停／結束有說明，問答與快速回饋分區。加入頁支援全形數字轉換，使用可見輸入標籤與數字鍵盤。
- **難度語意**：依原資料定義 1 = 太簡單、5 = 太難，修正表情方向，五個選項均有明確文字與輔助標籤。
- **品牌／無障礙**：共用狀態標籤、品牌頁首與載入／錯誤畫面。進行中使用綠色；狀態同時有文字，不只依顏色判斷。關鍵控制項放大，補上 icon button 標籤、選擇狀態與結果數值語意，支援繁中／英文。Tailwind 保留由 next-themes 在執行期加入的 `dark` 類別，避免既有深色色票被移除。

## 驗證

- Node 24：317 項測試通過，包括新增 8 項介面互動測試。
- TypeScript 與修改範圍 ESLint 通過。
- Next.js production build 通過；沒有提供 Gemini 設定時仍會出現專案既有的缺少金鑰提示。
- 真實加入頁：瀏覽器確認 390px 下輸入六位代碼後按鈕可用，沒有橫向溢出。
- 以實際 React 元件、示範資料產生獨立靜態 fixture，檢查講師頁 320／390／768／1440px 與學生頁 320／390／768px，以及講師深色模式。Fixture 不提供真實互動，也不繞過登入；互動行為另由 jsdom 測試執行。
- 建立／列表頁的 fixture 使用 AppLayout 替身，只檢查頁面內容，不宣稱驗證登入後的完整導覽殼層。

## 上線前仍需確認

使用具有有效設定的測試環境，以老師和學生兩個瀏覽器測試加入、投票、即時同步、問答、暫停／繼續、PDF 上傳與原生全螢幕投影。本次沒有連接正式資料庫，也沒有實際修改任何課堂資料。

可選的本機畫面檢查資料：執行測試時設定 `LIVE_PREVIEW_DIR`，上述介面測試會輸出示範 HTML；另使用 Tailwind 編譯 `app/globals.css` 為同目錄的 `style.css`。不要把 fixture 部署為正式路由。
