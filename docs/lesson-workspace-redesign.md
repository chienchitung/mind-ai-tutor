## 驗證與限制

- 109 項測試通過（原有 89 項＋新增 20 項）。
- 新增狀態函式與 React 靜態渲染測試：錯誤答案、空答案、成功、複習、最終關卡、表格、教師內容、SVG 與表單 ID。
- TypeScript 與 game-engine production build 通過。
- game-engine ESLint：零錯誤，6 項既有警告；這次未新增警告。
- 瀏覽器預覽受工具存取限制；未宣稱完成桌面／手機視覺驗收或真實 AI、Supabase 寫入端到端測試。
- 發布方式：沿用 master → Vercel 自動部署；以 Vercel 成功狀態與正式站 SVG 校驗確認版本。
- game-engine 建置不納入測試檔，避免獨立部署依賴父專案的 Vitest；測試仍由根目錄 npm test 執行。

## 部署前人工驗收

1. 320px、768px、1440px 檢查題目表格、分頁、AI 面板沒有頁面橫向溢出。
2. 前導、一般、綜合關卡各確認預設分頁及教材／互動嵌入不變。
3. 一般關卡答錯後修改答案，再答對；確認資料、奖励及解鎖與原邏輯一致。
4. 重新進入已完成關卡，確認「複習中」標示與既有解析。
5. 開關／展開聊天室，檢查草稿保留、快捷提問不自動送出、焦點返回及 Escape。
6. 使用實際 AI 設定測試中文組字 Enter、圖片上傳與貼上。
